What it is

Nexonic Sentinel is a free GitHub App that triages issues, reviews pull requests for bugs, scans your code each week, answers questions from your docs and merges safe dependency updates. It runs on GitHub Actions, so there is no server to keep online, and it uses free AI models.

It starts in a safe mode: nothing is sent to an AI model and nothing is merged until you switch it on in a settings file.

Features

Issue triage

Adds matching labels when they exist, thanks the author, asks for reproduction details on short bug reports and links relevant docs. Possible security reports are pointed to private vulnerability reporting.

Pull request bug review

On every new commit it reads the changed lines and posts concrete bugs it finds (file, line, why, suggested fix). It only comments: it never approves, blocks or pushes code. Needs ai = true.

Weekly code health report

Reads a few different source files each week and opens one report issue when it finds likely bugs. Needs ai = true.

Discussions Q&A

Answers from your README and docs/ only, lists its sources and says so when the docs do not cover a question.

Dependabot merges

Merges the update types you allow once every check has passed, from Dependabot-authored branches of the same repository only.

Welcomes contributors

Greets first-time contributors on pull requests.

Privacy and safety

  • It reads issues, pull requests, discussions and docs only on repositories you install it on.
  • Text leaves GitHub only when ai = true, and goes to free OpenRouter models, which may log prompts.
  • Findings are checked against the real diff or file before posting.
  • Model output is stripped of @mentions and hidden HTML; issue text is treated as untrusted data.
  • The model only writes comment text. It cannot merge, label or call any API, and the bot never runs code from your repository.
  • Uninstalling the app removes all of its access.

Quick start

Install the app on the repositories you choose, then optionally add .github/nexonic-sentinel.toml to change what it does:

Settings file

enabled = true
triage = true
welcome = true
discussions = true
ai = false          # allow sending text to free OpenRouter models
pr_review = true    # needs ai = true
code_scan = true    # needs ai = true
dependabot = []     # e.g. ["patch", "minor"]

Without the file, these are the defaults. To stop the bot on one thread, add the bot-off label. You can also run your own copy: create a GitHub App, add the secrets to your fork and set options in sentinel.toml.

Frequently asked questions

What is Nexonic Sentinel?

A free GitHub App and maintainer bot that triages issues, reviews pull requests for bugs, runs a weekly code health scan, answers Discussions from your docs and merges safe Dependabot updates.

Do I need a server?

No. It runs on GitHub Actions.

Is my code sent to an AI model?

Not by default. Nothing is sent until you set ai = true. Then the text being reviewed or answered goes to free OpenRouter models, which may log prompts, so do not enable it on repositories with code you cannot share.

Will it approve or push code?

No. Pull request review only comments; it never approves, blocks or pushes code, and it never runs code from your repository.

How does the Dependabot merging stay safe?

It only merges pull requests opened by dependabot[bot] from a branch of the same repository, with every commit authored by Dependabot, once every check has passed and the update type is one you allowed.

How do I turn it off?

Set enabled = false in .github/nexonic-sentinel.toml, add the bot-off label to a single thread, or uninstall the app.
